# 💇 Salon Booking Bot

## Overview

AI-powered booking system using Typebot + Google Sheets.

## Features

* Book appointments
* Select service, date, time
* Store data automatically

## Tech Stack

* Typebot
* Google Sheets
* Google Apps Script

## Workflow

User → Service → Details → Date/Time → Confirmation → Saved to Sheet
